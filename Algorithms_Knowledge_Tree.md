# 🌳  Algorithms Knowledge Tree

> A complete structured overview of algorithm knowledge — perfect for interview prep, problem-solving, and deep understanding.

---

<details>
<summary><b>🧱 Data Structure Algorithms</b></summary>

- **Array** – Sequential collection of elements; supports fast random access.
  - **Two Pointers** – Use two indices to solve interval/matching problems.
  - **Sliding Window** – Maintain a moving range for subarray/substring analysis.
  - **Prefix Sum** – Precompute sums to get subarray results in O(1).
  - **Counting** – Use frequency arrays or hash maps to count occurrences.
    
- **String** – Character sequence processing and pattern recognition.
  - **String Matching / KMP / Rabin-Karp / Z Algorithm** – Efficient substring search.
  - **Rolling Hash** – Hash-based fast comparison for substrings.
  - **Trie / Aho-Corasick** – Structures for dictionary and multi-pattern search.
  - **DP on String (LCS, Longest Palindrome)** – Dynamic programming string problems.
    
- **Hash Table** – Store and retrieve key-value pairs in O(1) average time.
  - **Hash Function / Set / Map** – Basis for lookup and membership operations.
    
- **Stack / Monotonic Stack** – LIFO structure; monotonic for range comparisons.
- **Queue / Monotonic Queue / Deque** – FIFO or double-ended; used in BFS and sliding window.
- **Heap (Priority Queue)** – Dynamic ordered data, supports efficient min/max retrieval.
- **Linked List / Doubly Linked List** – Dynamic structure supporting O(1) insertion/deletion.
  
- **Tree** – Hierarchical structure for ordered or relational data.
  - **Binary Tree / Binary Search Tree** – Basic and sorted tree types.
  - **Segment Tree / Lazy Segment Tree / BIT** – Range query and update structures.
    
- **Graph** – Nodes and edges; model relationships and networks.
  - **Representations (Adjacency List / Matrix)** – How graphs are stored.
  - **Union-Find / Disjoint Set** – Detect connected components efficiently.
  - **Minimum Spanning Tree (Prim / Kruskal)** – Minimum-cost edge connections.
  - **Shortest Path (Dijkstra / Bellman-Ford / Floyd-Warshall)** – Pathfinding algorithms.
  - **Max Flow / Min Cut (Edmonds-Karp / Dinic)** – Network flow optimization.
  - **Topological Sort** – Order DAG nodes respecting dependencies.
  - **Strongly Connected Component (Kosaraju / Tarjan)** – Find directed graph cycles.
  - **Eulerian / Hamiltonian Path** – Visit all edges/nodes exactly once.

</details>

<details>
<summary><b>🧩 Algorithm Design Techniques</b></summary>

- **Dynamic Programming (DP)** – Break problems into overlapping subproblems.
  - **Memoization** – Top-down recursion with caching.
  - **Tabulation** – Bottom-up DP with iterative filling.
    
- **Greedy** – Make locally optimal decisions aiming for global optimum.
  
- **Divide and Conquer** – Split problems, solve recursively, merge results.
  - **Binary Search** – Efficient search in sorted data.
  - **Merge Sort / Quick Sort / Quickselect** – Sorting and selection methods.
  - **Advanced:** Strassen’s Matrix Multiplication, FFT.
    
- **Backtracking** – Explore all possibilities and backtrack when constraints fail.
- **Recursion** – Solve problems via self-calling functions.

</details>

<details>
<summary><b>⚙️ Sorting Algorithms</b></summary>

- **Quick Sort** – Fast divide-and-conquer sorting; average O(n log n).
- **Merge Sort** – Stable and efficient; ideal for linked lists.
- **Heap Sort** – Uses heap property for sorting.
- **Counting Sort** – Non-comparison sort; based on counting occurrences.
- **Bucket Sort** – Distribute elements into buckets, sort within each.
- **Radix Sort** – Sort numbers by processing digits.
- **Shell Sort** – Optimized insertion sort with decreasing gaps.

</details>
